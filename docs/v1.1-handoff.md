## 3. リリース時の作業手順 (operator)

### 3.1 事前に揃える 2 アカウント

1. **Stripe** (https://dashboard.stripe.com/register)
   - Products → 4 つ作成: `L1 ¥2,980/月` `L2 ¥3,480/月` `L3 ¥3,980/月` `保護者プラン ¥4,980/月` (全て JPY 月次サブスク)
   - 各 Price ID をメモ
   - Developers → **Webhooks** → Add endpoint:
     - URL: `https://script.google.com/macros/s/<GAS_DEPLOYMENT_ID>/exec?action=stripe_webhook&secret=<URL_SECRET>`
     - Events: `checkout.session.completed`, `customer.subscription.deleted`, `charge.refunded`, `invoice.payment_failed`
     - `<URL_SECRET>` は `openssl rand -hex 16` で生成
2. (任意) Google Drive: Welcome 音声を別ファイルにする場合のホスト先

### 3.2 GAS Script Properties に登録

| 名前 | 値 |
|---|---|
| `STRIPE_SECRET_KEY` | `sk_test_...` (テスト) → 後で `sk_live_...` |
| `STRIPE_WEBHOOK_URL_SECRET` | 上で生成した URL secret |
| `STRIPE_PRICE_L1` | L1 の Price ID |
| `STRIPE_PRICE_L2` | L2 の Price ID |
| `STRIPE_PRICE_L3` | L3 の Price ID |
| `STRIPE_PRICE_PARENT` | 保護者プランの Price ID |
| `WELCOME_AUDIO_URL` (任意) | フォロー時の音声 URL を切り替えたい場合のみ |

### 3.3 Cloud Shell で親子 day1/day2 を生成

```bash
cd ~/sho-eigo-gas
git checkout claude/v1.1-parent-trial-realign
git pull
bash scripts/build_parent_trial.sh
git add pages/trial/parent_day1.html pages/trial/parent_day2.html
git commit -m "Generate parent_day1/day2 from production trial pages"
git push
```

### 3.4 main にマージして自動デプロイ

PR を Ready → Merge。`deploy.yml` が:
1. `clasp push` → GAS にコード反映
2. FTP 同期 → 静的ファイル反映
3. verify endpoints で 200 確認

## 4. v1.1 で起こる「並走」の干渉ゼロ確認

| 既存 cron | 対象 | v1.1 での動き |
|---|---|---|
| `checkAndSendScheduled` (毎時) | 進行中ユーザー全員 | 既存通り、SC-PARENT が新仕様で動く以外は変更なし |
| その他 v2 cron | — | 凍結ルールにより未追加 |

新規ユーザーフロー:
- ファネル A (一般): `/lp/` → `/trial/day1.html` → `/trial/day2.html` → LINE → SC-MAIN 配信 → `/next-step.html` → Stripe
- ファネル B (親子): `/trial/parent_lp.html` → `/trial/parent_day1.html` → `/trial/parent_day2.html` → LINE → SC-PARENT 配信 (Day0 → +1 → +3 → +5) → `/next-step.html?from=parent` → Stripe

**干渉ポイントなし**: 同じユーザーが両ファネル同時にいることはなく、SC-MAIN と SC-PARENT は scenarioId で排他。
